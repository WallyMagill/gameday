# gameday v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** k9s/vim command grammar, per-game depth (Zoom tabs + global plays feed), standings/config/date-travel/odds/alerts/mouse, and a rendered-variants style lab — on the existing RedZone board.

**Architecture:** `App` gains an `InputMode` (Normal/Command/Filter) and a `View` enum that replaces `focused_id`; each view renders from `src/views/`; one keymap table drives dispatch, footer, and help. All new data is additive ESPN mapping behind the existing provider trait, fixture-tested offline.

**Tech Stack:** Rust, Ratatui 0.29, crossterm (mouse feature already enabled), tui-big-text 0.7, ureq, serde_json. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-08-30-gameday-v2-design.md` — read it first; this plan argues from it.

## Global Constraints

- Branch `redzone-draw`; commit per task; never push, never touch `main`.
- `cargo test` green and fully offline after every task (fixtures only; grep tests for `ureq|http` must stay clean).
- ESPN host is `site.web.api.espn.com` only; browser-like User-Agent; no API key.
- Terminal-legal rendering only; theme roles come from `theme::current()` — no raw `Color::Rgb` in draw code.
- Errors name actual vs expected and the knob (e.g. `unknown command "foo", valid: nfl|nba|…`).
- Visual tasks end with the dump verify loop: `GAMEDAY_DUMP_FONT=<cascadia path> cargo run -q -- dump`, then Read the affected PNG(s) and look before committing.
- Every commit message ends with the Co-Authored-By + Claude-Session trailer used by prior commits on this branch (see `git log`).
